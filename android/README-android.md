# اپ اندروید Windroida

یه پوسته ساده دور رابط وب (WebView) + سرویس پس‌زمینه برای اعلان. **این کد اینجا کامپایل و روی گوشی تست نشده** (ابزار اندروید تو محیط من نیست)؛ اگه موقع ساخت خطا داد، متن خطا رو بفرست تا درستش کنم.

## چی داره
- آیکون واقعی تو لیست برنامه‌ها، بدون نصب گواهی تو گوشی. برنامه اولین بار اثر انگشت (SHA-256) گواهی سرور رو نشون می‌ده؛ با اثری که تو پنجره `start.bat` چاپ شده مقایسه کن و «اعتماد می‌کنم» رو بزن. از اون به بعد فقط همون گواهی قبوله (اگه عوض بشه وصل نمی‌شه).
- اعلان پیام وقتی برنامه بسته/پس‌زمینه‌ست: یه سرویس پیش‌زمینه هر ۲۵ ثانیه از `POST /notify` سرور می‌پرسه (long-poll). به گوگل/FCM وابسته نیست. متن پیام و اسم فرستنده رو نشون می‌ده؛ با زدن روی اعلان همون چت باز می‌شه.
- بعد از ریستارت گوشی خودش دوباره شروع می‌شه. موقع اولین ورود از شما می‌خواد برنامه از بهینه‌سازی باتری مستثنی بشه (برای پایدار موندن اعلان لازمه).
- میکروفون/دوربین (ویس، تماس، اتاق)، انتخاب فایل برای آپلود و دانلود فایل (تو پوشه Downloads) پشتیبانی می‌شه.

## ساخت APK — راه ۱: GitHub (بدون نصب چیزی)
1. کل پوشه پروژه رو تو یه مخزن GitHub بذار (خصوصی هم می‌شه).
2. تب Actions ← «Build Windroida APK» ← Run workflow.
3. بعد از چند دقیقه، فایل `windroida-apk` رو از Artifacts دانلود کن (داخلش `app-debug.apk`) و رو گوشی نصب کن (اجازه «نصب از منبع ناشناس»).

## ساخت APK — راه ۲: Android Studio (روی کامپیوتر خودت)
1. Android Studio رو از developer.android.com/studio نصب کن (نسخه Koala یا جدیدتر). اینترنت لازمه، چون موقع اولین باز کردن چند صد مگابایت چیز دانلود می‌کنه.
2. File ← Open ← همین پوشه `android` (نه پوشه اصلی پروژه) رو انتخاب کن.
3. صبر کن «Gradle Sync» تموم بشه (پایین صفحه). اگه گفت SDK 34 نصب نیست، روی لینک «Install» بزن.
4. منو Build ← Build Bundle(s) / APK(s) ← **Build APK(s)**.
5. وقتی تموم شد بالا راست «locate» میاد؛ فایل تو `android/app/build/outputs/apk/debug/app-debug.apk` هست. رو گوشی کپی کن و نصبش کن (اجازه «نصب از منبع ناشناس»).
اگه Gradle Sync خطا داد، متن کامل خطا رو برام بفرست.

## استفاده
1. برنامه رو باز کن، آدرس سرور رو بزن: `https://IP-SERVER:8087`
2. اثر انگشت رو تأیید کن.
3. وارد حساب شو. اجازه اعلان و باتری رو بده.
4. **عوض کردن آدرس/آی‌پی سرور:** تو برنامه منو ← تنظیمات ← «🌐 آدرس سرور (اپ اندروید)». اگه سرور عوض شده باشه و صفحه باز نشه، خودش پنجره «تغییر آدرس سرور» رو نشون می‌ده. با آدرس جدید باید اثر انگشت گواهی رو دوباره تأیید کنی و دوباره وارد بشی.

## محدودیت‌های شناخته‌شده
- اگه WebSocket روی گواهی خودامضا تو WebView وصل نشد (تو بعضی نسخه‌ها پیش میاد)، بگو تا راه جایگزین بذارم.
- دانلود فایل‌های `blob:` پشتیبانی نمی‌شه.
- امضای APK از نوع debug هست (برای استفاده شخصی کافیه، نه برای فروشگاه).
